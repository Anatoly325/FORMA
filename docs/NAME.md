# Название языка

Полное имя: **Форма Учеватова Кая**.

Короткое техническое имя: **FORMA**.

Расширение исходников: **`.forma`**.

Название предложено Анатолием Учеватовым 19 октября 2026 года. Оно объединяет
его фамилию и имя Кай, выбранное для общения с ИИ-ассистентом в этом проекте.

Главная идея проекта — свобода работы ИИ: самостоятельное создание, применение
и развитие инструментов для выполнения задач.

В представлении проекта и заголовках используется полное имя. В командах,
идентификаторах, технических примерах и именах файлов применяется FORMA / forma.

Изменение полного имени не меняет семантику исполняемого профиля 0.1.0,
формат исходников, идентификатор среды или ревизии ранее созданных инструментов.
